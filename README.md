# Tripledemic SHIELD Project

Dates: January 2025 - Present  

This repository includes:

### Tripledemic Paper
- tripledemic_model
    - seir.R --> Full tripledemic SEIR model
      - seir_source.R --> Source functions/code for tripledemic SEIR code 
      - seir_params.R --> All parameters needed for various seir models 
    - beta_vals.Rmd --> Code to find beta values from target R0
    - tripledemic.Rmd --> Code to run SEIR & build figures
      - tripledemic_source.R --> Source code for building figures in tripledemic.Rmd
    - seir_by_pathogen.R --> SEIR code by individual pathogen (COVID, RSV, Flu)
